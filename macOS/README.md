# macOS Support Fundamentals

I’m building my practical knowledge of macOS as part of my IT support training. My focus is on becoming familiar with the macOS user experience, handling common support requests, and using built-in tools to investigate problems.

## Core Areas

### User Environment

* Finder
* Dock
* Menu bar
* Spotlight
* System Settings
* Applications
* User accounts

### System Administration

* User and administrator permissions
* File and folder permissions
* Software updates
* Storage management
* Startup and login items

### Troubleshooting Tools

* Activity Monitor
* Disk Utility
* System Information
* Console
* Terminal

### Connectivity

* Wi-Fi
* Ethernet
* DNS
* DHCP
* Bluetooth
* VPN
* Network settings

### Security

* FileVault
* Keychain
* Gatekeeper
* Privacy permissions
* System security settings

## Current Goal

My aim is to become confident handling common macOS helpdesk issues and to understand how Macs are managed in a business environment.

I’m continuing to build this knowledge through hands-on exercises, troubleshooting practice, and clear documentation.
