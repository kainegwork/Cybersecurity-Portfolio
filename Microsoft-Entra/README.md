## Microsoft 365 Licensing

A Microsoft Entra ID account provides the user's identity, but access to Microsoft 365 services also depends on licensing.

Licences can provide access to services such as:

- Exchange Online / Outlook
- Microsoft Teams
- OneDrive
- SharePoint
- Microsoft 365 desktop applications

Licences can be assigned directly to users or through group membership.

If a user can sign in successfully but cannot access a specific Microsoft 365 service, I would check:

1. Whether the user has the correct licence assigned.
2. Whether the relevant service plan is enabled.
3. Whether the licence is assigned directly or through a group.
4. Whether there is a wider service or application issue.

## User Offboarding

When an employee leaves an organisation, the first priority is to remove their access safely.

A typical offboarding process may include:

1. Block or disable the user's sign-in.
2. Revoke active sessions.
3. Remove the user from relevant groups.
4. Remove or reassign Microsoft 365 licences.
5. Review access to shared resources and applications.
6. Preserve or transfer required business data such as email or OneDrive files.
7. Delete the account only when it is appropriate and in line with company policy.

The important principle is to stop access first, then handle licences, permissions and data in a controlled way.
